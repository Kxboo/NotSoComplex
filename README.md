# NotSoComplex - Model To Radiant Brush Tool

NotSoComplex is a lightweight converter tool designed to transform 3D models into native Call of Duty Radiant brush geometry. It enables mappers to convert mesh files directly into editable `.map` brush structures for Black Ops Radiant.

[Download Latest Release](https://github.com/Kxboo/NotSoComplex/releases)

---

## Features

* **Multi-Format Support:** Convert `.xmodel_export`, `.xmodel_bin`, `.json`, `.cast`,`.map`, and `.obj` formats.
* **Direct Brush Generation:** Translate complex mesh topology and convex bounds into clean `.map` brush primitives.
* **Direct Brush Editing:** (More support in progress)

## Usage

1. Launch App
2. Select your target model file (`.xmodel_export`, `.xmodel_bin`, `.json`, `.cast`, or `.obj`).
3. Edit and Generate Brushes within tool
4. Configure your export settings and output directory.
5. Convert and open the generated `.map` brush file directly in Radiant.
